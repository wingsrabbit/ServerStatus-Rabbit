# 版本更新目录

这个目录保留两类内容：

- 历史 update 文档：用于交接、回溯和理解版本演进
- 当前正式版本文档：用于标记唯一有效主线版本

整理原则：

- 当前 NG 分支的正式版本只认 v0.131。
- `main` 上的正式版本仍是 v0.130。
- 历史 update 文件继续保留，但它们只是资料，不代表当前仍然存在多个正式版本。

命名规则：

- 文件名直接使用最终版本号。
- 当前 NG 分支唯一保留版本：v0.131。
